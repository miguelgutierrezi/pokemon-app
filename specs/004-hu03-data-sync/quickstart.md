# Quickstart validation: HU-03 Data Synchronization

**Feature**: `004-hu03-data-sync` | **Date**: 2026-10-17

Contracts: [collection-api.yaml](./contracts/collection-api.yaml),
[env-config.md](./contracts/env-config.md). Data model: [data-model.md](./data-model.md).

## Prerequisites

- Features 001–003 stack runnable (`docker compose`, JDK 21)
- Fresh Postgres volumes so Flyway V2/V3 apply (seed present)
- Network access to PokeAPI **or** WireMock stubs for offline IT
- No new env keys (reuse `POSTGRES_*`, `POKEAPI_BASE_URL`)

## 1. Configure & start

```bash
cp .env.example .env
docker compose down -v   # fresh volumes → seed
docker compose up --build -d
docker compose ps
```

Expected: postgres, backend, frontend healthy/up; migrations through V3.

## 2. Seed present (SC-004)

```bash
curl -s "http://localhost:8080/api/v1/collection?page=1&size=9" | python3 -m json.tool
```

Expected: `200`; `content` includes national numbers **1, 2, 3**
(Bulbasaur line) with snapshot fields and sample proprietary tags such as
`first-partner` / `field-notes` / `forest` (never `favorites`).

Via proxy:

```bash
curl -s "http://localhost:3000/api/v1/collection?page=1&size=9" | python3 -c \
  'import sys,json; print([r["nationalNumber"] for r in json.load(sys.stdin)["content"]])'
```

## 3. Import happy path (SC-001)

```bash
curl -s -i -X POST "http://localhost:8080/api/v1/collection" \
  -H "Content-Type: application/json" \
  -d '{"nationalNumber":25}'
```

Expected: **201**; `Location: /api/v1/collection/25`; body with snapshot
fields (name, types, heightM, weightKg, imageUrl, generation, syncedAt) and
proprietary fields empty (`localizedName` / `location` null, `tags` `[]`).
Uncached import ≤ 3 s when PokeAPI is healthy.

## 4. Duplicate → 409 (SC-002)

```bash
curl -s -i -X POST "http://localhost:8080/api/v1/collection" \
  -H "Content-Type: application/json" \
  -d '{"nationalNumber":25}'
```

Expected: **409** problem+json; list/get still show a single row for 25.

## 5. Get local vs not in collection (SC-005)

```bash
curl -s -i "http://localhost:8080/api/v1/collection/1"
curl -s -i "http://localhost:8080/api/v1/collection/9999"
```

Expected: `1` → **200** full local record; `9999` → **404** problem+json
whose detail clearly means not in the **local** collection (distinct from
catalog not-found wording on `GET /api/v1/pokemon/{id}`).

## 6. Import errors (SC-003)

```bash
# validation
curl -s -i -X POST "http://localhost:8080/api/v1/collection" \
  -H "Content-Type: application/json" \
  -d '{}'
curl -s -i -X POST "http://localhost:8080/api/v1/collection" \
  -H "Content-Type: application/json" \
  -d '{"nationalNumber":0}'

# catalog miss (no local row created)
curl -s -i -X POST "http://localhost:8080/api/v1/collection" \
  -H "Content-Type: application/json" \
  -d '{"nationalNumber":9999}'
```

Expected: missing/`0` → **400** problem+json; catalog miss → **404**
problem+json; never stack traces or upstream URLs.

Catalog down (point `POKEAPI_BASE_URL` at a closed port; restart backend):

```bash
curl -s -i -X POST "http://localhost:8080/api/v1/collection" \
  -H "Content-Type: application/json" \
  -d '{"nationalNumber":26}'
curl -s "http://localhost:8080/api/v1/collection/26" -w "\n%{http_code}\n"
```

Expected: import → **502** problem+json; get 26 → **404** (nothing saved).
