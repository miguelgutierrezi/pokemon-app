# Quickstart validation: HU-04 Local Data Modification

**Feature**: `005-hu04-local-update` | **Date**: 2026-10-17

Contracts: [collection-api.yaml](./contracts/collection-api.yaml),
[env-config.md](./contracts/env-config.md). Data model: [data-model.md](./data-model.md).

## Prerequisites

- Feature 004 stack runnable (`docker compose`, JDK 21, jq optional)
- Fresh or migrated DB through Flyway **V4** (`version` column)
- No new env keys

## 1. Configure & start

```bash
cp .env.example .env
docker compose up --build -d
docker compose ps
```

Expected: healthy stack; migrations through **V4**.

## 2. Read version on seed (additive vs 004)

```bash
curl -sS 'http://localhost:8080/api/v1/collection/1' | jq '{nationalNumber, localizedName, version}'
```

Expected: **200**; `version` present (typically `0` for untouched seed).

## 3. Update proprietary fields (SC-004 / SC-003)

```bash
curl -sS -i -X PUT 'http://localhost:8080/api/v1/collection/1' \
  -H 'Content-Type: application/json' \
  -d '{"localizedName":"Bulbizarre","location":"Pallet Town garden","tags":["first-partner","forest"],"version":0}'
```

Expected: **200**; body shows updated proprietary fields; `version` is **1**;
snapshot fields (`name`, `types`, `syncedAt`, …) unchanged. Completes
≤ 200 ms locally.

## 4. Stale version → 409 stale-version (SC-002)

```bash
curl -sS -i -X PUT 'http://localhost:8080/api/v1/collection/1' \
  -H 'Content-Type: application/json' \
  -d '{"localizedName":"X","location":null,"tags":[],"version":0}'
```

Expected: **409**; `type` = `urn:problem-type:stale-version`; detail mentions
reload/retry. Distinct from duplicate-import `urn:problem-type:conflict`.

## 5. Malformed / unknown / missing property → 400

```bash
# missing property (version omitted)
curl -sS -i -X PUT 'http://localhost:8080/api/v1/collection/1' \
  -H 'Content-Type: application/json' \
  -d '{"localizedName":null,"location":null,"tags":[]}'

# unknown / read-only snapshot field
curl -sS -i -X PUT 'http://localhost:8080/api/v1/collection/1' \
  -H 'Content-Type: application/json' \
  -d '{"localizedName":null,"location":null,"tags":[],"version":1,"name":"Hack"}'

# non-JSON
curl -sS -i -X PUT 'http://localhost:8080/api/v1/collection/1' \
  -H 'Content-Type: text/plain' \
  -d 'nope'
```

Expected: omitted/`name` → **400** problem+json naming the field (no Jackson
package leaks); non-JSON → **415** problem+json.

## 6. Missing record → 404 local wording

```bash
curl -sS -i -X PUT 'http://localhost:8080/api/v1/collection/150' \
  -H 'Content-Type: application/json' \
  -d '{"localizedName":null,"location":null,"tags":[],"version":0}'
curl -sS -i -X DELETE 'http://localhost:8080/api/v1/collection/150'
```

Expected: both **404**; detail `Pokémon 150 is not in the local collection`.

## 7. Delete → 204 then re-import

```bash
curl -sS -i -X DELETE 'http://localhost:8080/api/v1/collection/1'
curl -sS -i 'http://localhost:8080/api/v1/collection/1'
curl -sS -i -X POST 'http://localhost:8080/api/v1/collection' \
  -H 'Content-Type: application/json' \
  -d '{"nationalNumber":1}'
```

Expected: delete **204**; get **404** local; import **201** with
`version: 0` (catalog untouched by delete).

## 8. Automated verification

```bash
cd backend
./mvnw -Dmaven.compiler.showDeprecation=true verify
```

Expected: domain/application/infrastructure/web tests green including
concurrent update (one 200 / one stale-version 409) and e2e IT.
